# my_pet_projects

Добро пожаловать в моё портфолио личных проектов (pet projects) по Data Science!

Этот репозиторий является пространством для моих независимых исследований и практической отработки навыков в различных областях анализа данных и машинного обучения. Каждый проект представляет собой самостоятельное погружение в конкретную задачу, начиная от этапов сбора, очистки и предобработки данных.

Здесь вы найдете примеры:

Исследовательского анализа данных (EDA) и статистического анализа, включая проверку гипотез и A/B-тестирование.

Разработки и оценки классических моделей машинного обучения для задач классификации и регрессии.

Применения глубоких нейронных сетей в областях обработки естественного языка (NLP) и компьютерного зрения.

Анализа и прогнозирования временных рядов.

Создания признаков (Feature Engineering) и визуализации данных для получения actionable insights.

Проекты демонстрируют мою способность к самостоятельному поиску решений, критическому мышлению и применению продвинутых аналитических техник для извлечения ценности из данных.

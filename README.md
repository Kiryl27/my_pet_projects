# revenue-analysis-by-period

Этот проект представляет собой интерактивное десктопное приложение (на базе Python и Tkinter) для глубокого анализа и визуализации причин изменений выручки между любыми заданными временными периодами.

Основные возможности и функционал:

Гибкое сравнение периодов: Приложение позволяет выбрать любой "текущий" период (месяц, квартал, полугодие, произвольный диапазон) из данных за 2024-2025 годы (и более ранние, если они доступны в структуре файлов) и сравнить его с любым "базисным" периодом любого года.

Детализация причин расхождений: Используя математический подход, основанный на ежемесячных Excel-отчетах (содержащих разницу между текущим и предыдущим месяцем по различным статьям), проект выявляет и количественно оценивает вклад каждой статьи доходов/расходов в общую разницу выручки между выбранными периодами.

Автоматизированная обработка Excel-данных: Приложение автоматически считывает, очищает и агрегирует финансовые данные из множества структурированных Excel-таблиц, подготавливая их для анализа.

Визуализация и интерпретация: На выходе пользователь получает четкий отчет о причинах расхождения выручки, представленный как в табличном виде (с детализацией по каждой статье), так и в виде наглядной визуализации (графиков), что позволяет быстро определить ключевые драйверы изменений.

Пользовательский интерфейс (GUI): Интуитивно понятный графический интерфейс обеспечивает удобный выбор анализируемых периодов и проектов.

Проект демонстрирует навыки в финансовой аналитике, работе с Excel-данными, статистическом анализе, построении GUI-приложений и эффективной визуализации для поддержки принятия бизнес-решений.
